% ---------- DISCUSSIONI, METTERE SE DOC È UN VERBALE ----------
\section{Discussioni}
\begin{itemize}
    \item Durante la riunione si sullo stato di svolgimento delle issue precedentemente concordate, sulla realizzazione del PoC, in particolare sulle funzionalità da implementare in seguito alla scelta di un sottoinsieme dei requisiti identificati nell'Analisi dei Requisiti, e sugli impegni dovuti alla sessione di esami.
    \item Dalle discussione riguardanti il PoC è emersa la necessità di contattare il proponente Miriade SRL riguardo alla gestione degli account utente nell'applicazione.
    \item Dalle discussioni sullo stato delle issue è risultato il mancato completamento di alcune issue, che quindi verranno rimandate a questo sprint: 
    \begin{itemize}
        \item Implementazione del cruscotto di qualità nel PdQ.
        \item Inserimento metodi di testing nel PdQ
        \item Creazione github action per automazione della formatazzione dei termini da glossario nella documentazione
        \item Implementazione github action per calcolo dell'Indice di Gulpease.
    \end{itemize}
    \item È stato deciso di inserire il cruscotto con la descrizione di ogni grafico nel Piano di Progetto nell'ultimo sprint prima dell'RTB.
    \item In seguito alle discussioni, sono state decise le seguenti attività da svolgere, in aggiunta al completamento delle attività non completate dello sprint 4:
    \begin{itemize}
        \item Inserire nel Piano di Progetto il consuntivo dello sprint 4 e iniziare la sezione dello sprint 5.
        \item Inserire la data di candidatura RTB nella sezione 4.1 del Piano di Progetto.
        \item Aggiungere attività nella sezione 4.2 del Piano di Progetto.
    \end{itemize}
    \item Infine è stata decisa l'assegnazione dei ruoli per il prossimo sprint:
    \begin{center}
        \textbf{Amministratore\ap{G}} $\rightarrow$ Dennis Parolin\\
        \textbf{Responsabile\ap{G}} $\rightarrow$ Ferdinando Fracasso\\
        \textbf{Analista\ap{G}} $\rightarrow$ Marco Sanguin, Giovanni Visentin\\
        \textbf{Programmatore\ap{G}} $\rightarrow$ Riccardo Manisi, Gabriele Scaggiante, Giovanni Visentin\\
        \textbf{Verificatore\ap{G}} $\rightarrow$ Dennis Parolin, Gabriele Scaggiante
    \end{center}
\end{itemize}
