\section{Discussioni}
\begin{itemize}
    \item La riunione è stata svolta principalmente per un riallineamento generale di tutti i componenti del gruppo. In una prima fase, ciascun membro ha illustrato le attività completate durante lo Sprint precedente. Le principali attività svolte sono:
    \begin{itemize}
        \item Progettazione diagrammi dell'Architettura di Backend, diagrammi delle classi per le lambda e diagrammi e sezione nella Specifica Tecnica per materiale informativo;
        \item Scrittura sezioni dei design pattern utilizzati e sezione dell'Architettura Backend e API per autenticazione, luoghi sicuri e materiale informativo.
        \item Sviluppo frontend per homepage, contatti fidati e chatbot.
        \item creazione tabella per tracciamento requisiti e grafici metriche di Processo.
    \end{itemize}
    Successivamente sono stati esposti anche i compiti non portati a termine entro i tempi previsti. Sono state individuate le attività da posticipare e includere nel nuovo Sprint:
    \begin{itemize}
        \item Scrittura sezioni relative all'Architettura Backend e alle lambda.
        \item Sviluppo frontend del diario.
        \item Scrittura diagrammi delle classi per autenticazione e integrazione con altri diagrammi.
        \item Specifica dei Test di Integrazione per Backend.
    \end{itemize}
    Inoltre, sono state discusse le attività da svolgere durante lo Sprint 10, divise per ruolo, che includono:
    \begin{itemize}
    \item Responsabile:
    \begin{itemize}
        \item Redazione di due verbali esterni (uno con la Proponente e uno con Professor Cardin).
        \item Creazione delle Issue, setup delle Issue nel Project e assegnazione delle Issue.
        \item Redazione riassunto di periodo dello Sprint 10 nel PdP.
    \end{itemize}
    \item Progettista:
    \begin{itemize}
        \item Correzioni sulla base di quanto ci viene detto da Cardin.
        \item Modifica della sezione “Architettura Logica” nella Specifica Tecnica, ora spiega una Architettura layered. Da spiegare la nuova Architettura esagonale.
        \item Controllare la sezione “Architettura di Deployment” nella Specifica Tecnica. Dobbiamo essere sicuri rispecchi quanto è stato deciso fino ad ora.
        \item Scrittura sezioni Specifica Tecnica sull’Architettura di Backend (mancano autenticazione, homepage, chatbot, diari, dead man’s switch, contatti fidati).
        \item Scrittura sezioni Specifica Tecnica sull’Architettura di frontend (homepage, autenticazione).
        \item Scrittura sezioni Specifica Tecnica sulle classi dentro le Lambda.
        \item Controllo generale della correttezza dei diagrammi, riportare sul documento di diagrammi corretti.
        \item Scrittura diagrammi della classi per l’autenticazione e integrazione con gli altri diagrammi.
    \end{itemize}
    \item Programmatore:
    \begin{itemize}
        \item Frontend e Backend autenticazione (prioritaria).
        \item Frontend Dead man’s Switch (nelle impostazioni).
        \item Frontend Impostazioni.
        \item Frontend Diario.
        \item Frontend luoghi sicuri.
        \item Frontend materiale informativo.
        \item Backend luoghi sicuri.
        \item Backend materiale informativo.
        \item Backend Diario.
        \item Backend Chatbot (con Ollama per i prompt).
        \item Backend Dead man’s Switch.
    \end{itemize}
    \item Verificatore:
    \begin{itemize}
        \item Verifica e controllo del passaggio dei test.
    \end{itemize}
\end{itemize}
    \item Infine, abbiamo suddiviso i ruoli tra i membri del gruppo, continuando a ruotarli come fatto in precedenza. La distribuzione è la seguente:
    \begin{center}
        \textbf{Responsabile} $\rightarrow$ Giovanni Visentin\\
        \textbf{Progettista} $\rightarrow$ Marco Sanguin,Riccardo Manisi\\
        \textbf{Programmatore} $\rightarrow$ Gabriele Scaggiante, Dennis Parolin, Marco Sanguin, Giovanni Visentin, Ferdinando Fracasso, Riccardo Manisi\\
        \textbf{Verificatore} $\rightarrow$ Ferdinando Fracasso, Dennis Parolin, Gabriele Scaggiante
    \end{center}
\end{itemize}
